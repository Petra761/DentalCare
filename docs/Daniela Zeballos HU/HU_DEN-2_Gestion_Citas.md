# DEN-2: Gestion de Citas

## Descripcion
El sistema debe permitir a los usuarios autorizados gestionar las citas
odontologicas desde un panel administrativo.

## Criterios de Aceptacion
1. Visualizar listado de citas con datos del paciente, servicio y estado
2. Crear nuevas citas con validacion de horario y conflictos
3. Editar citas existentes (cambiar fecha, hora, servicio, cliente)
4. Cambiar estado de la cita (Pendiente, Confirmada, Cancelada, Completada)
5. Eliminar citas (soft delete)
6. Validar que no existan solapamientos de horario

# DEN-8: Agendar Cita

## Descripcion
El sistema debe permitir agendar una nueva cita seleccionando paciente,
servicio, fecha y hora.

## Criterios de Aceptacion
1. Seleccionar paciente existente (busqueda por nombre/CI/telefono)
2. Seleccionar servicio disponible
3. Elegir fecha y hora dentro del horario laboral
4. Validar que la fecha no sea anterior al dia actual
5. Validar que la hora sea en intervalos de 30 minutos
6. Validar que no existan conflictos de horario con el paciente
7. Validar que no existan conflictos de horario con el odontologo
8. Generar codigo unico de cita automaticamente

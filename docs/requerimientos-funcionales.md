# Reglas derivadas de los Requerimientos Funcionales

Las siguientes reglas establecen las condiciones que debe cumplir el sistema a partir de los requisitos funcionales definidos para la gestión de la clínica dental.

| Tipo | Nro | Regla derivada del RF                   | Descripción                                                                                                                                                                                        |
| ---- | --- | --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RF-R | 1   | Identificación obligatoria del paciente | Para iniciar el proceso de reserva mediante WhatsApp, el paciente debe proporcionar obligatoriamente su CI, nombre completo y número de teléfono.                                                  |
| RF-R | 2   | Validación de datos del paciente        | El sistema debe validar los datos proporcionados por el paciente antes de permitir el registro de una cita.                                                                                        |
| RF-R | 3   | Agendamiento automatizado               | El asistente virtual debe permitir al paciente realizar el proceso de agendamiento de una cita mediante WhatsApp.                                                                                  |
| RF-R | 4   | Disponibilidad de horarios              | El sistema solo debe permitir seleccionar horarios disponibles en la agenda al momento de registrar o reprogramar una cita.                                                                        |
| RF-R | 5   | Consulta de información institucional   | El asistente virtual debe proporcionar información autorizada sobre el odontólogo, su experiencia profesional, los servicios y las ventajas de la clínica.                                         |
| RF-R | 6   | Restricción de información comercial    | El asistente virtual debe responder las consultas sobre tratamientos de acuerdo con las políticas comerciales configuradas por la clínica.                                                         |
| RF-R | 7   | Orientación para tratamientos complejos | Cuando la información solicitada sobre un tratamiento no esté autorizada o requiera valoración profesional, el asistente virtual debe orientar al paciente a solicitar una consulta de valoración. |
| RF-R | 8   | Reprogramación ante cancelación         | Antes de completar una cancelación solicitada por el paciente, el asistente virtual debe ofrecer horarios alternativos disponibles para facilitar la reprogramación.                               |
| RF-R | 9   | Sincronización de operaciones           | Toda reserva, modificación, reprogramación o cancelación debe actualizar la información correspondiente en la agenda.                                                                              |
| RF-R | 10  | Gestión de citas desde el panel web     | El Administrador y el Operador pueden crear, consultar, modificar y cancelar citas desde el panel web.                                                                                             |
| RF-R | 11  | Gestión de ficha clínica                | El Operador debe poder registrar y actualizar la información médica del paciente mediante la ficha clínica digital.                                                                                |
| RF-R | 12  | Exportación de información              | El sistema debe permitir a los usuarios autorizados exportar y descargar la agenda y los reportes estadísticos en formatos digitales.                                                              |
| RF-R | 13  | Generación de reportes                  | El sistema debe generar reportes estadísticos en formatos adecuados para su consulta y posterior impresión física.                                                                                 |
| RF-R | 14  | Métricas estadísticas                   | El sistema debe calcular y mostrar métricas relacionadas con el rendimiento de la atención y la conversión de pacientes.                                                                           |
| RF-R | 15  | Autenticación de usuarios               | Todo usuario del panel web debe iniciar sesión utilizando credenciales válidas antes de acceder a las funcionalidades del sistema.                                                                 |
| RF-R | 16  | Acceso según rol                        | El sistema debe otorgar acceso a las funcionalidades según el rol asignado al usuario autenticado.                                                                                                 |
| RF-R | 17  | Consulta de citas por WhatsApp          | El paciente debe poder consultar el estado y los detalles de sus citas mediante el asistente virtual.                                                                                              |
| RF-R | 18  | Reprogramación mediante WhatsApp        | El paciente debe poder reprogramar una cita seleccionando únicamente horarios disponibles.                                                                                                         |
| RF-R | 19  | Cancelación mediante WhatsApp           | El paciente debe poder cancelar una cita mediante WhatsApp cuando lo solicite.                                                                                                                     |
| RF-R | 20  | Confirmación automática                 | El sistema debe enviar una confirmación automática al paciente después de registrar, modificar o reprogramar una cita.                                                                             |
| RF-R | 21  | Recordatorios personalizados            | El sistema debe enviar recordatorios de citas de acuerdo con la anticipación configurada por el paciente.                                                                                          |
| RF-R | 22  | Gestión de tratamientos                 | El Administrador y el Operador pueden crear, consultar, modificar y eliminar tratamientos registrados en el sistema.                                                                               |
| RF-R | 23  | Gestión de alergias                     | El Administrador y el Operador pueden crear, consultar, modificar y eliminar alergias registradas en el sistema.                                                                                   |
